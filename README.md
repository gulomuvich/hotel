## 🌟 Asosiy Imkoniyatlar (Key Features)

### 1. 🏨 Barcha Xonalarni Onlayn Band Qilish (Room Booking Engine)
- **Deluxe Ocean Suites, Presidential Suites, Royal Penthouse va Oceanfront Shaxsiy Villalar**.
- Jonli sana va narx kalkulyatori: Kechalar soni, mehmonlar va qo'shimcha VIP xizmatlarga ko'ra avtomatik narx hisoblash.
- Qo'shimcha VIP xizmatlar (Rolls-Royce kutib olish, Dom Pérignon Vintage shampan, Cheksiz Spa, 24/7 Butler).
- **Elektron VIP Bron Vaucheri**: QR-kodli, chop etiladigan va saqlanadigan rasmiy tasdiqnoma generatsiyasi.

### 2. 👥 Ishchilar Soni & Xodimlar Nazorati Dashboardi (Staff & Operations Center)
- **142 nafar faol ishchilar soni** va real vaqtda yangilanuvchi KPI statistikasi:
  - Jami ishchilar soni
  - Hozir navbatchilikda turgan xodimlar soni
  - Faol xizmat so'rovlari va o'rtacha javob vaqti
  - Xonalar bandlik foizi (84%)
- **Bo'limlar bo'yicha hisobot**:
  - Qabulxona & Konsyerj (18 xodim)
  - Oshxona & Restoran (36 xodim)
  - Xona Xizmati & Tozalik (42 xodim)
  - VIP Haydovchilar (16 xodim)
  - Xavfsizlik & Muhandislik (14 xodim)
  - Spa & Salomatlik (16 xodim)
- **Xodimlar ro'yxati boshqaruvi**: Yangi xodim qo'shish modal formasi, navbatchilik holatini o'zgartirish (Navbatchilikda, Dam olishda, Tanaffusda), qidirish va filtrlash.
- **Jonli mehmonxona xizmatlari jurnali (Live Activity Feed)**.

### 3. 🚗 VIP Haydovchi va Hashamatli Avtopark (Chauffeur & Fleet Transfer)
- Hashamatli avtopark: **Rolls-Royce Phantom VIII, Mercedes-Maybach S680, Cadillac Escalade Platinum, Bentley Flying Spur Mulliner**.
- Aeroportdan kutib olish, soatbay xizmat yoki shaharlararo transfer buyurtma qilish formasi.
- Litsenziyali haydovchilar va zudlik bilan tasdiqlash tizimi.

### 4. 🍽️ Gurme Oshxona & 3 Mishelin Yulduzli Restoran (Fine Dining & Room Service)
- Michelin yulduzli gurme menyusi (Wagyu A5 Steyk, Beluga Ikra, Brittany Moviy Omar, 24K Oltin Shokolad va Vintage Shampanlar).
- **Xonaga 24/7 Taom Yetkazish (Room Service Cart)**: Interaktiv savatcha, xona raqamini kiritish va jonli yetkazish buyurtmasi.
- **Restoranda Stol Band Qilish (Table Reservation)**: Panoramik ochiq terasa, Royal VIP zali yoki sommelier burchagidan joy band qilish.

### 5. 🌐 Xalqaro Ko'p Tillilik va Valyuta Konvertatsiyasi
- **3 ta Til**: 🇺🇿 O'zbekcha (UZ), 🇬🇧 English (EN), 🇷🇺 Русский (RU).
- **3 ta Valyuta**: USD ($), UZS (so'm), EUR (€).

## 🎨 Dizayn Tizimi (Design Aesthetics & Mantine UI)
- **Mantine UI v7**: `@mantine/core`, `@mantine/hooks`, `@mantine/dates`, `@mantine/notifications`, `@tabler/icons-react`.
- **Ranglar uyg'unligi**: Deep Obsidian (`#080c14`), Royal Navy (`#0f1626`), Champagne Gold (`#d4af37`), Brushed Gold Gradients.
- **Glassmorphism**: Fon xiralashtirish (Backdrop-filter blur 20px), oltin hoshiyalar va glow effektlar.
- **Tipografiya**: Cinzel & Playfair Display (Qirollik sarlavhalari) va Plus Jakarta Sans (Matnlar).
- **Mobil moslashuvchanlik**: Barcha ekran o'lchamlari (Smartfonlar, Planshetlar, Noutbuklar, 4K Monitorlar) uchun 100% moslashuvchan.

## 🚀 Ishga Tushirish (Installation & Development)

```bash
# 1. Loyihani klonlash
git clone https://github.com/gulomuvich/hotel.git

# 2. Loyiha papkasiga o'tish
cd hotel

# 3. Paketlarni o'rnatish
npm install

# 4. Mahalliy dasturchi serverini ishga tushirish
npm run dev

# 5. Production build yaratish
npm run build
```
